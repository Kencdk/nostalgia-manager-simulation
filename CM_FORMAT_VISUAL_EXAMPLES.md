## Comparison with Other Formats

### Simple Format (OLD)
Just shows positions: `MC, MR, AMR` (hard to parse, takes space)

### CM Format (NEW)
Groups intelligently: `M C/R, AM R` (clear, compact, informative)

### Full Verbose
Would be: "Central Midfielder, Right Midfielder, Right Attacking Midfielder" (too long)

## Benefits in Context

### Quick Scanning
At a glance, you can see:
- **GK**: Goalkeeper only
- **D C**: Pure centre-back
- **M C/R**: Versatile midfielder (centre/right)
- **M/AM R/L, F C/R/L**: Ultimate versatility

### Team Building
Easily identify:
- **Specialists**: Single position format (e.g., `M C`)
- **Utility players**: Multiple sides (e.g., `D C/R/L`)
- **Versatile attackers**: Multiple roles (e.g., `M/AM R/L`)
- **Multi-role players**: Combined format (e.g., `DM/M C, D C`)

### Tactical Planning
Understand coverage:
- Need right-sided cover? Look for `/R` or `R/`
- Need attacking depth? Look for `AM` or `F`
- Need versatile sub? Look for multiple role groups

## Technical Details

### Column Width
Changed from `%-3s` to `%-8s` to accommodate:
- Simple: `GK` (2 chars)
- Medium: `M C/R` (5 chars)
- Complex: `M/AM R/L` (8 chars)
- Very complex: `M/AM R/L, F C/R/L` (would require even more, but rare)

### Alignment
Left-aligned for readability:
```
 1  GK         Player Name
12  M C/R      Player Name
 7  M/AM R/L   Player Name
```

### Consistency
Same format used throughout:
- Player details
- Squad lists
- Tactics screens
- Match displays
- Team overviews

This creates a consistent, professional experience throughout the application.
